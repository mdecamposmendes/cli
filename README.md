# valet-sh CLI

Go-based CLI that orchestrates Ansible playbooks for managing local development
environments for Magento, PHP, and other projects.

When invoked with no arguments it launches an interactive Bubble Tea TUI;
with arguments it shows a live execution panel and delegates to Ansible.
